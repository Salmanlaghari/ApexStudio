### 0.1 Python suite result

```
Ran 39 tests in 7.162s
FAILED (errors=1)

ERROR: test_hash_and_signer_are_recorded (test_apk_provenance.ApkProvenanceTest)
  File "scripts/apk-provenance.py", line 25, in provenance
    checksum = hashlib.file_digest(stream, "sha256").hexdigest()
AttributeError: module 'hashlib' has no attribute 'file_digest'
```

**Verdict: environment issue, not a repo bug.** `hashlib.file_digest` was added in **Python 3.11**;
this sandbox has 3.10.12. The project's own CI presumably uses 3.11+.
**Fix (optional, makes the script portable to 3.8+):**

```python
# scripts/apk-provenance.py — replace the file_digest call
def _sha256_file(path: str) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as stream:
        for chunk in iter(lambda: stream.read(1024 * 1024), b""):
            h.update(chunk)
    return h.hexdigest()
```

### 1.3 ❌ MISSING — this is where your request #1 bites

You asked for AI on **video / image / song / audio — all of them**. Right now:

| Gap | Detail |
|---|---|
| **No AI on still images at all** | `GlobalModerationEnforcement` hard-restricts every protected action to `ClipType.VIDEO`. `ClipType.IMAGE` exists and there is a photo editor, but no AI action can run on it. Even MODNet and ESPCN explicitly refuse stills. |
| **No AI on audio/music at all** | Audio side is pure DSP: `SpectralDenoiser`, `VoiceNoiseSuppressor`, `PcmAudioExtractor`, `TrackWaveformCache`. There is **no** beat/BPM detection, no music-structure/segment detection, no auto-duck under voice, no smart-fit-music-to-video-length, no vocal/speech-vs-music discrimination. |
| **Zero online AI** | By design: 100% on-device, "no cloud". Nothing calls a remote inference API. |
| **Whisper is tiny only** | No `base`/`small`. Accuracy ceiling on noisy audio. |
| **No multi-language control** | Whisper auto-detects; word-alignment is English-only. |

### 1.4 📦 APK-size situation — your instinct was right

`app/src/main/assets/models/` = **232 MB** on disk:

```
 95 MB  alignment/wav2vec2-base-960h-int8.onnx
 90 MB  whisper/tiny-decoder.int8.onnx
 26 MB  background_removal/modnet_photographic.onnx
 13 MB  whisper/tiny-encoder.int8.onnx
 7.8 MB mediapipe/mediapipe-hand-landmarker.task
 5.8 MB mediapipe/mediapipe-pose-landmarker.task
 3.8 MB mediapipe/mediapipe-face-landmarker.task
 0.8 MB whisper/tiny-tokens.txt
 0.25 MB mediapipe/selfie_segmenter.tflite
 0.24 MB super_resolution/super-resolution-10.onnx
```

**Good news:** `app/build.gradle.kts` (≈line 31-47) already **excludes large model weights from
APK/AAB assets by default** via the `stageRuntimeAssets` Sync task, and `OnDemandModelPacks`
downloads them on explicit user request into `filesDir` with SHA-256 + exact-byte verification.
So the "keep it as a download, don't bloat the APK" requirement is **already architected**.

**Concern:** a 95 MB alignment model for an *optional English-only* feature is a poor trade.
Recommend an explicit opt-in download (it already is one) and surfacing the size **before**
download starts.

## 3. What I recommend — priority order

1. **Unlock export for face-crop tracks** → unblocks face-aware reframe + face tracking in one go.
   Highest value-per-effort item in the whole repo.
2. **Add an image/photo AI scope** to `GlobalModerationEnforcement` (`withExistingProjectImage…`)
   → unlocks MODNet + ESPCN + MediaPipe on `ClipType.IMAGE`.
3. **Add audio AI** — beat/BPM detection, auto-duck, smart music fit. All doable with deterministic
   DSP + optionally a tiny permissive model. No policy risk.
4. **Keep every new model on-demand** — never bundle. Show size before download.
5. **Device-validate export parity** — cannot be done in this sandbox, needs your phone.

### 4.1 Real bug found and fixed

`verify-free-ai-policy.py` flagged four MediaPipe entries whose `source` pointed at a
**floating `/latest/` URL** while a SHA-256 was pinned in the lock file:

```
.../face_landmarker/float16/latest/face_landmarker.task
.../pose_landmarker_lite/float16/latest/pose_landmarker_lite.task
.../hand_landmarker/float16/latest/hand_landmarker.task
.../selfie_segmenter/float16/latest/selfie_segmenter.tflite
```

If upstream ever re-publishes those bytes, every cached hash fails and the feature breaks for
already-installed users. Pinned to the versioned `/1/` path — which `AiFeatureRegistry` already
cited as the canonical source. Re-ran `verify-ai-models.py`: **13/13 assets verified, exit 0**, no regression.

## 5. Build on your machine

