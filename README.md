## 💎 Why ApexStudio?

### 🚀 100% On-Device — No Cloud, No Waiting
Everything happens on your phone. No uploads, no waiting, no internet needed. Your data stays with you — privacy guaranteed.

### 🎬 Professional Quality — Beyond CapCut
20+ professional LUTs for Hollywood-style grading. Frame-accurate trimming. Multi-layer timeline. This is not a toy — it's a professional tool.

### ⚡ Hybrid Engine — 3x Faster
| Engine | Use Case | Speed |
|--------|----------|-------|
| **Media3** | Fast path, instant preview | ⚡⚡⚡ |
| **FFmpeg** | Heavy processing, 4K export | 🎬🎬🎬 |
| **GStreamer** | Real-time effects, zero lag | 🚀🚀🚀 |

### 🎨 134 Animated 3D Stickers — FREE
Original designs, Lottie-powered, 60fps smooth. Hearts, stars, fire, confetti, animals, emojis. Better quality than CapCut/TikTok — and completely free.

### 💰 100% FREE — No Watermark, No Ads, No Subscription
- ✅ No watermark on exports
- ✅ No ads, no interruptions
- ✅ No subscription — all features free forever
- ✅ No hidden costs

### 📱 Mobile-First Design
Built for phone, by phone users. Touch-optimized — drag, pinch, swipe to edit. Lightweight 40MB APK, installs in seconds.

## 🛠️ Tech Stack

| Layer | Technology | Details |
|-------|-----------|---------|
| **UI** | Jetpack Compose | Material 3 + custom cinematic theme |
| **Media** | AndroidX Media3 | ExoPlayer, Transformer, Effect |

## 📦 Installation

### Requirements
- Android 8.0+ (API 26)
- 100MB free storage
- 2GB RAM recommended

### Build from Source

```bash
# Clone the repository
git clone https://github.com/Salmanlaghari/ApexStudio.git
cd ApexStudio

# Build debug APK
./gradlew :app:assembleDebug

# Install on device
./gradlew :app:installDebug
```

### Download
- **GitHub Releases** — [Latest APK](https://github.com/Salmanlaghari/ApexStudio/releases)

## 🎵 Music Library

| Tab | Source | Requirements |
|-----|--------|--------------|
| **Discover** | Jamendo API v3 — 500k+ Creative-Commons tracks | Free `JAMENDO_CLIENT_ID` |
| **Offline** | Built-in synthesized tracks | Nothing |
| **Import** | Audio picker (MP3/M4A/WAV/OGG) | Nothing |

### Getting a Free Jamendo Key
1. Create account at [developer.jamendo.com](https://developer.jamendo.com/)
2. Register an app to get a **Client ID**
3. Add to `local.properties`: `JAMENDO_CLIENT_ID=your_key_here`
4. Rebuild — Discover tab lights up automatically

> **Note:** Without a key, Discover shows setup steps. Offline + Import keep working.
