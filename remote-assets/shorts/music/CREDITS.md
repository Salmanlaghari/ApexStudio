# ApexStudio Shorts music assets

Each audio file is hosted separately from Android app assets and downloaded only after the user chooses a template. The app checks the declared byte count and SHA-256 before making a file usable. The single source-of-truth catalog is `app/src/main/assets/shorts/music_catalog.json`; its URLs point to these files on the repository's `main` branch.
