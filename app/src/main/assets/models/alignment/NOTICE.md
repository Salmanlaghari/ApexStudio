# Bundled English acoustic alignment model

The bundled `wav2vec2-base-960h-int8.onnx` is the `model_quantized.onnx` conversion from [onnx-community/wav2vec2-base-960h-ONNX](https://huggingface.co/onnx-community/wav2vec2-base-960h-ONNX), pinned revision `729c1a6730fb549c20a1c73a3d3f96f11020225e`. It derives from Meta/Facebook's [wav2vec2-base-960h](https://huggingface.co/facebook/wav2vec2-base-960h), licensed Apache-2.0. The license text is included in `LICENSE`. Original wav2vec 2.0 authors: Alexei Baevski, Henry Zhou, Abdelrahman Mohamed and Michael Auli. The ONNX conversion was published by ONNX Community. No endorsement is implied.

Exact artifact: <https://huggingface.co/onnx-community/wav2vec2-base-960h-ONNX/resolve/729c1a6730fb549c20a1c73a3d3f96f11020225e/onnx/model_quantized.onnx>. Bytes: 95,212,816. SHA-256: `1d9a366c27b2966625cd5035ac3db8847c53bba617169912bb251b42975a3a22`. `config.json`, `preprocessor_config.json` and `vocab.json` are preserved from that same revision and pinned in the parent inventory.

This is a 16 kHz English acoustic CTC model, not a multilingual aligner, translation model, moderation classifier, or speech synthesizer. Its fine-tuning data is LibriSpeech English. The app uses genuine model emissions to align known Whisper text; it does not divide phrase duration evenly among words. Unsupported characters, incompatible outputs and low-confidence/no-path alignments fail rather than producing invented word times. The confidence floor is an engineering rejection heuristic, not a calibrated accuracy guarantee.

Inputs are float32 `[1,samples]`, zero-mean/unit-variance normalized with epsilon `1e-7`. Outputs are float32 logits `[1,frames,32]`; blank token is 0, word delimiter is 4, ASCII letters/apostrophe use the preserved vocabulary. Model convolution stride is 320 samples (20 ms), receptive field is 400 samples (25 ms). Timings are approximate acoustic frame measurements, not phonetic ground truth.

Weights ship in the APK; no runtime download/cloud API is used. A verified app-private copy adds about 95 MB of storage. The selected alignment windows are bounded; decoding still uses the existing bounded whole-audio PCM extractor, so this is not constant-memory streaming. Android RAM/latency, acoustic accuracy across accents/noise/music and full preview/export acceptance need real-device testing. Host CPU inference and recorded-emission unit tests do not establish those properties.
